# Bhagavad Gita — Experience the Divine Wisdom

This repository contains a small static site (vanilla HTML/CSS/JS) that presents the Bhagavad Gita content with a cinematic, editorial design.

What I changed (automated):

- Added this `README.md` describing the project.

Dev / Run

Open `index.html` in a browser or serve via a simple static server. Example using Python 3:

```bash
python3 -m http.server 5500
# then open http://127.0.0.1:5500
```
